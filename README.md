Japan in Numbers — a national statistics site for Japan: population, regions and more, with real figures, sources and years, as a static offline site.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
Then open out/app/index.html in a browser. No network requests, no build step: app/ is plain static files.
